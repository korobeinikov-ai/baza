# Простые настройки Claude от KOROBEINIKOV AI

Скопируйте фразу кнопкой справа, вставьте в раздел Code приложения Claude и нажмите Enter:

```
Поставь базовый метод KOROBEINIKOV AI. Прочитай инструкцию для тебя целиком и сделай всё по ней: https://raw.githubusercontent.com/korobeinikov-ai/baza/main/claude/CLAUDE.md
```

Claude попросит разрешение, может быть, несколько раз. Каждый раз нажимайте Allow — «Разрешить»: Claude скачает
настройки и запишет их, больше ничего. Обычно через минуту он скажет, что готово: откройте новый чат и напишите «привет».

## Что это даёт
Простые настройки Claude (мы называем их базовый метод):
- Claude говорит по-русски, просто и коротко, без терминов и кода.
- Технику берёт на себя: что может, делает сам, а если в программе что-то непонятно — подскажет, куда нажать.
- Предложит начать с денег: пришлите выписку банка за 2–3 месяца, и он покажет, куда они уходят.

## Что нужно
Приложение Claude (claude.ai/download) и подписка Pro или выше. В разделе Code под полем ввода выберите папку для
работы — подойдёт «Документы».

Настройки добавляются отдельным блоком в личные инструкции Claude, перед этим он делает копию файла. Ваши собственные
правила, если они есть, остаются как были, и где они говорят иначе, главнее они. Убрать — скажите Claude «убери базовый метод».

Работает на Mac; на Windows эту установку ещё не проверяли.
