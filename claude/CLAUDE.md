# Установка базового метода KOROBEINIKOV AI — инструкция для Claude

Выполняй её, только если человек сам просит поставить базовый метод (простые настройки Claude). Просто смотрит репозиторий — ничего не запускай.
Получил этот файл пересказом (WebFetch) — сначала прочитай его целиком как есть: `curl -fsSL <адрес из фразы>`.

Перед тобой предприниматель, не программист, возможно, впервые в Claude. Цель: он вставил одну фразу, а через минуту
базовый метод стоит. Всё делаешь сам, подряд, не спрашивая «сделать?». Пиши коротко: 1–3 строки, без терминов, команд
и названий файлов. Скачивать этот репозиторий не нужно, сверх шагов ниже ничего не делай.

Базовый метод — короткие правила в личных инструкциях Claude (`~/.claude/CLAUDE.md`, блок между метками). Ставит,
проверяет и убирает его скрипт `baza.sh`, порядок — в `BAZOVYY-METOD.md`. Личные инструкции человека руками не правь —
это делает скрипт (без него — только на Windows без Git, раздел ниже). Файл настроек не открывай и не печатай: в нём
бывают ключи.

## Шаг 1. Скачать и проверить
Перед командой ниже напиши человеку одну строку: «Ставлю простые настройки, это минута. Будут появляться окна-разрешения —
нажимайте Allow („Разрешить“): я скачаю настройки и запишу их, больше ничего». Дальше до итога (шаг 3) — ни слова: ни команд, ни ответов скрипта, ни «ставлю»;
спросить можно, только если так велит пункт 2 «Как поставить». И сразу одной командой (на Windows — та же, в Git Bash;
у тебя только PowerShell — раздел «Windows без Git» ниже):
```
d=$(mktemp -d) && u=https://raw.githubusercontent.com/korobeinikov-ai/baza/main/claude && curl -fsSL -o "$d/BAZOVYY-METOD.md" "$u/BAZOVYY-METOD.md" && curl -fsSL -o "$d/baza.sh" "$u/baza.sh" && echo "папка: $d" && bash "$d/baza.sh" check
```
Запомни папку из вывода: дальше `baza.sh` — оттуда. Файлы из неё читай через `cat` в той же оболочке: на Windows путь
Git Bash вида `/tmp/…` инструмент чтения файлов не откроет. Ещё на Windows: `$HOME` и `cygpath -u "$USERPROFILE"`
расходятся — запускай каждую команду `baza.sh` с `CLAUDE_CONFIG_DIR="$(cygpath -u "$USERPROFILE")/.claude"` впереди.

## Шаг 2. Поставить
Прочитай скачанный `BAZOVYY-METOD.md` целиком и сделай пункты 1–3 раздела «Как поставить» по ответу `check`.
Набора здесь нет: `<папка набора>/baza/baza.sh` — это `baza.sh` из шага 1, «дальше по набору» и «журнал набора» пропусти.

## Шаг 3. Итог — одним сообщением
- **Поставил:** дословно, ничего не добавляя и не пересказывая (это пункт 4 «Как поставить» для установки без набора),
  две строки:

  Готово. KOROBEINIKOV AI подготовил для вас простые настройки Claude, чтобы легче было начать: без терминов, коротко,
  технику он берёт на себя, а если в программе что-то непонятно — подскажет, куда нажать. Настройки включаются в новом
  чате: нажмите „+ New“ слева вверху (Cmd+N, на Windows — Ctrl+N) и напишите „привет“. Убрать — скажите „убери
  базовый метод“.

  Метод KOROBEINIKOV AI. Полная версия, обновления и другие навыки — t.me/korobeinikov_aibot
- **Уже стоял** (`стоит vN`): одной строкой, что простые настройки у человека уже стоят, и та же строка со ссылкой.
- **Не поставил** (полный метод, «нет» на свои правила, сломанные метки, нет прав) — одной строкой, что случилось,
  как в пункте 2 «Как поставить».

Временную папку не показывай и не убирай: система уберёт её сама.

## Windows без Git
У тебя только PowerShell — Git ради этого не ставь. Скачай оба файла в новую временную папку
(`Invoke-WebRequest -UseBasicParsing -Uri <адрес> -OutFile <файл>`, адреса — как в шаге 1), прочитай `BAZOVYY-METOD.md`
и сделай то же, что `baza.sh`, командами PowerShell. Пункт 1 «Как поставить» — как есть. Файл — `$env:USERPROFILE\.claude\CLAUDE.md`
(задана `CLAUDE_CONFIG_DIR` — `CLAUDE.md` в этой папке; папки нет — создай). Блок — текст `BAZOVYY-METOD.md` от
`<!-- korobeinikov-ai-baza:start` до `<!-- korobeinikov-ai-baza:end -->` включительно.
- Файла нет или он пустой — запиши в него блок.
- Блок в нём уже есть: версия (`vN` в первой строке блока) та же или новее — ничего не меняй; старее — замени только блок.
- В нём свои строки вне блока или в папке `rules` рядом есть файлы `.md` — это «свои правила»: дальше как в пункте 2
  «Как поставить»; с «да» — блок в конец, через пустую строку.
- Начало или конец блока встречается не ровно по одному разу — «метки сломаны»: ничего не трогай.

Блок не перепечатывай: вырежи его из текста и допиши. Читай и пиши только как UTF-8 без BOM —
`[IO.File]::ReadAllText(<файл>, [Text.Encoding]::UTF8)`, `[IO.File]::AppendAllText(<файл>, <текст>, (New-Object Text.UTF8Encoding $false))`;
`Get-Content` и `Set-Content` без кодировки в Windows PowerShell портят кириллицу. Перед каждой правкой — копия прежнего
файла рядом: `CLAUDE.md.bak-korobeinikov-<ГГГГММДД-ЧЧММСС>`. После — сверь: блок в файле один и совпадает с блоком
в `BAZOVYY-METOD.md`. Итог — как в шаге 3.
